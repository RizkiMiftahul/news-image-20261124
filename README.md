One image that sums up the world news of Tuesday 24 November 2026, drawn as an
editorial front page: Ukraine's naval drones sink a Russian warship off Libya
as the lead story, with Jensen Huang's return to Nvidia, the Russian strike on
Zaporizhzhia, the Gaza strikes that killed Hamas's security chief, tankers
hitting mines in the Strait of Hormuz, the collapse of the COP31 climate
talks, and the Ras Al Khaimah bus crash around it. `render.py` draws the page
with PIL from the vendored fonts in `fonts/`; `main.py` writes the stored
image to `/output/entry.png`, byte for byte, on every run.

## Run it

```sh
python3 main.py
```
